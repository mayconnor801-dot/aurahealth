# Aura Health — Medical & Preventive Care Landing Page

A high-converting, clean, and modern medical landing page built with HTML5, SASS, and JavaScript. Designed with a heavy focus on UX/UI, accessibility, and high performance.

## 🚀 Key Features
- **CTA-Focused Hero Section:** Integrated appointment booking form.
- **Dynamic UX:** Interactive JavaScript form feedback and success handling.
- **Modern Styling:** Built with SASS using CSS Grid & Flexbox.
- **SEO Ready:** Complete Open Graph and Twitter meta tags.

## 🛠️ Tech Stack
- HTML5
- SASS (CSS3)
- JavaScript (ES6+)
- FontAwesome Icons
